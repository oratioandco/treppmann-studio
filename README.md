# Treppmann Studio

Shared Astro source for two bilingual public sites:

- `studio.treppmann.design`: workflow digitization and internal tools studio
- `treppmann.de`: Tobias Treppmann's AI product and transformation leadership profile

- German: `/`
- English: `/en/`
- Static Astro build deployed through GitHub Pages

The personal site uses English at `/` and German at `/de/`. Build it with
`npm run build:personal`; `npm run sync:personal` rebuilds it and synchronizes
the sibling `treppmann-de` deployment repository.

The selected work was led by Tobias Treppmann across employed, contract and
independent consulting roles. Company names describe the context of the work;
they are not presented as a Treppmann Studio client list.
